# AGENTS.md — ДУДКА

> Корневые правила студии: [`../AGENTS.md`](../AGENTS.md).

## Границы продукта

«ДУДКА» владеет локальным discovery, peer-сессией, общим чатом квартиры, хвостом истории и передачей файлов **только в LAN**.  
Не владеет identity/RBAC (и не использует `Доверие` в MVP), облачным хранилищем, push через интернет, интеграциями с «Диалогами».

## Регуляторный контур

Исходящий интернет в рантайме запрещён требованиями [`docs/specs/network.md`](docs/specs/network.md). Это продуктовая граница, не оптимизация.

## Базовый стек первой реализации

- Go: engine (`dudkad`), протокол, discovery, файлы, Linux TUI.
- Flutter: iOS / Android / Windows / macOS UI по [`DESIGN.md`](DESIGN.md).
- Связка Flutter↔Go: локальный loopback API engine (только `127.0.0.1` / UDS); не тащить протокол в два языка.
- Данные: локальные файлы устройства (peer_id, ник, кэш хвоста/файлов); без внешней БД.
- Новая зависимость от облака, mDNS как единственный discovery, auth-провайдер — требуют явного решения владельца / ADR.

## Скорость — фича №1 студии

Числовые бюджеты — в [`docs/specs/product.md`](docs/specs/product.md) (NFR). Бюджет не повышают ради зелёного теста.

## Инженерные инварианты

- Сначала спецификация с устойчивыми ID `DUD-*`, затем red-first тест и минимальная реализация.
- Каждый принимаемый SHA: ноль warnings и errors.
- Один факт — один источник истины; wire-протокол версионируется.
- Engine не инициирует соединения за пределы локальных интерфейсов / RFC1918 / link-local (см. DUD-NET-*).
- Новый/изменённый production-файл держать обозримым; не плодить второй UI-стек без причины.
- Правило бойскаута обязательно; большой несвязанный рефакторинг — отдельная карточка.

## Работа агента

- Без явной просьбы/карточки не начинай runtime-код и магазинные пайплайны.
- Перед правкой читай `PRODUCT.md`, `DESIGN.md`, релевантный `docs/specs/*`.
- UI: не нарушать anti-goals бренда (регистрация, облако, комнаты/коды, баннеры, сложные настройки; без CRT-фанатизма).
- Порезы тулинга — в [`../papercuts/dudka.md`](../papercuts/dudka.md).
- Не коммить секреты, реальные личные переписки, дампы чужих сетей.
