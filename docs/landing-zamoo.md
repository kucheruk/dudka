# Лендинг Дудки на zamoo.team (P120)

Статус: Accepted · 2026-07-28 (P120–P124)  
Страница: `zamoo.team/dudka.html` · футер главной → «Дудка».

## Один экран — смысл

**Дудка** — локальный чат квартиры: текст и файлы в одном Wi‑Fi, без аккаунтов и без облака.

- Открыл → уже в общем чате с теми, кто онлайн рядом.
- Только LAN (не мессенджер в интернете).
- GUI: iOS / Android / Windows / macOS · Linux: терминальный клиент.
- Кнопка отправки: «ОТПРАВИТЬ».

## Блоки страницы

1. Герой: имя + одна фраза + oneliner/CTA (когда артефакты готовы — P124).
2. Скриншоты (плейсхолдеры → живые — P123).
3. Установщики по ОС: macOS · Windows · Linux · Android · iOS (ссылки — P123).
4. Коротко «как это работает» (LAN, без аккаунта).

## Non-goals копирайта

Регистрация, облако, «комнаты/коды», сравнение с Telegram, нарко-/сленг-глаголы отправки.
