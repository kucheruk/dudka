# DUD-PRD — Продукт и границы

Статус документа: Draft  
Владелец: ДУДКА  
Последнее смысловое изменение: 2026-07-27

## Назначение и границы

ДУДКА даёт небольшой семье в одной LAN общий чат для текста и файлов без аккаунтов и без интернета в рантайме. Успех: открыл клиент на устройстве в том же Wi‑Fi — видишь online и можешь отправить сообщение.

### Non-goals

- Комнаты, коды приглашений, аккаунты, пароли, E2E как продуктовая фича MVP.
- Голос, видеозвонки, push через интернет, облачный sync.
- Runtime-зависимости от Доверия, Диалогов, Досье.
- Callhome / телеметрия / проверка обновлений по сети в рантайме.

## Требования

### DUD-PRD-101

Priority: P0  
Status: Draft

Клиент при наличии хотя бы одного online peer в той же LAN позволяет отправить текстовое сообщение так, чтобы оно появилось в ленте у этого peer без создания аккаунта и без ввода пароля.

Проверка:

- два устройства в одной сети: сообщение видно получателю ≤ 2 s при обычном квартирном Wi‑Fi;
- на пути нет экрана регистрации/логина;
- evidence: сценарий ручной приёмки + автотест протокола на двух loopback-peers.

Зависимости: DUD-CHAT-101, DUD-NET-101  
ADR: не требуется

### DUD-PRD-102

Priority: P0  
Status: Draft

Платформы MVP: iOS, Android, Windows, macOS (GUI) и Linux (текстовый TUI). Поведение чата и discovery совпадает по wire-протоколу.

Проверка:

- одна версия major протокола на всех клиентах одной поставки;
- TUI может обменяться текстом с Flutter-клиентом в одной LAN;
- evidence: matrix smoke на поддерживаемых платформах или документированный пробел с карточкой.

Зависимости: DUD-NET-110  
ADR: не требуется

### DUD-PRD-103

Priority: P0  
Status: Draft

UI и пользовательские строки MVP — только на русском языке.

Проверка:

- в GUI/TUI нет обязательных английских user-facing строк вне имён файлов/MIME;
- evidence: checklist локализации в CI или ручной проход.

Зависимости: нет  
ADR: не требуется

### DUD-PRD-110

Priority: P0  
Status: Draft

В UI запрещены: обязательная регистрация, облачные намёки, комнаты/коды, рекламные баннеры, экран сложных настроек (больше минимального: ник и поиск соседей).

Проверка:

- дерево экранов MVP содержит только first-run ник, чат, мини-настройки;
- review UI против этого списка;
- evidence: скриншоты + ссылка на DESIGN.md.

Зависимости: DUD-UI-101  
ADR: не требуется

### DUD-PRD-120

Priority: P1  
Status: Draft

NFR latency (квартирный Wi‑Fi, ≤ 10 peers): доставка текста peer→peer p95 ≤ 500 ms; появление нового peer в списке после его announce p95 ≤ 3 s; старт GUI до интерактивной ленты p75 ≤ 2 s на mid-range телефоне.

Проверка:

- замер на стенде двух машин + телефон;
- evidence: таблица замеров в карточке приёмки.

Зависимости: DUD-NET-101  
ADR: не требуется

### DUD-PRD-140

Priority: P2  
Status: Draft

Решение о лицензировании через Дьяк / Community без лицензии / иной модели фиксируется до первой публичной поставки бинарников. Пока решение не принято, runtime callhome не реализуется.

Проверка:

- в коде нет callhome-эндпоинтов;
- при принятии модели — отдельная спека с ID, иначе статус остаётся Draft с датой пересмотра.

Зависимости: нет  
ADR: потребуется при выборе модели
