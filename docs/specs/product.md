# DUD-PRD — Продукт и границы

Статус документа: Draft  
Владелец: ДУДКА  
Последнее смысловое изменение: 2026-07-27

## Назначение и границы

ДУДКА даёт небольшой семье в одной LAN общий чат для текста и файлов без аккаунтов и без интернета в рантайме. Успех: открыл клиент на устройстве в том же Wi‑Fi — видишь online и можешь отправить сообщение.

### Non-goals

- Комнаты, коды приглашений, аккаунты, пароли, E2E как продуктовая фича MVP.
- Голос, видеозвонки, push через интернет, облачный sync.
- Runtime-зависимости от Доверия, Диалогов, Досье.
- Callhome / телеметрия / проверка обновлений по сети в рантайме.

## Требования

### DUD-PRD-101

Priority: P0  
Status: Draft

Клиент при наличии хотя бы одного online peer в той же LAN позволяет отправить текстовое сообщение так, чтобы оно появилось в ленте у этого peer без создания аккаунта и без ввода пароля.

Проверка:

- два устройства в одной сети: сообщение видно получателю ≤ 2 s при обычном квартирном Wi‑Fi;
- на пути нет экрана регистрации/логина;
- evidence: сценарий ручной приёмки + автотест протокола на двух loopback-peers.

Зависимости: DUD-CHAT-101, DUD-NET-101  
ADR: не требуется

### DUD-PRD-102

Priority: P0  
Status: Draft

Платформы MVP: iOS, Android, Windows, macOS (GUI) и Linux (текстовый TUI). Поведение чата и discovery совпадает по wire-протоколу.

Проверка:

- одна версия major протокола на всех клиентах одной поставки;
- TUI может обменяться текстом с Flutter-клиентом в одной LAN; *(P064)*
- два Flutter-клиента обмениваются текстом и файлом (два peer/устройства); *(P071: `./scripts/flutter_ff_test.sh`)*
- evidence: matrix smoke на поддерживаемых платформах или документированный пробел с карточкой; `./scripts/flutter_send_test.sh`, `./scripts/flutter_ff_test.sh`.

Зависимости: DUD-NET-110  
ADR: не требуется

### DUD-PRD-103

Priority: P0  
Status: Accepted

UI и пользовательские строки MVP — только на русском языке.

Проверка:

- в GUI/TUI нет обязательных английских user-facing строк вне имён файлов/MIME и slash-команд TUI (`/nick`, `/announce`, …); *(P072)*
- status strip: «онлайн N», состояния «ок» / «один» / «нет сети»; лейблы «СОСЕДИ» / «ЛЕНТА» / «ВВОД»; файл в ленте — «ФАЙЛ …»; *(P072)*
- evidence: `apps/dudka/test/ru_ui_test.dart`, `internal/tui/ru_ui_test.go`, `./scripts/ru_ui_test.sh` (P072).

Зависимости: нет  
ADR: не требуется

### DUD-PRD-110

Priority: P0  
Status: Draft

В UI запрещены: обязательная регистрация, облачные намёки, комнаты/коды, рекламные баннеры, экран сложных настроек (больше минимального: ник и поиск соседей).

Проверка:

- дерево экранов MVP содержит только first-run ник, чат, мини-настройки; *(P062/P063/P066)*
- review UI против этого списка;
- evidence: `SettingsNickScreen` nick-only + `./scripts/flutter_settings_test.sh` (P066); DESIGN.md.

Зависимости: DUD-UI-101  
ADR: не требуется

### DUD-PRD-120

Priority: P1  
Status: Draft

NFR latency (квартирный Wi‑Fi, ≤ 10 peers): доставка текста peer→peer p95 ≤ 500 ms; появление нового peer в списке после его announce p95 ≤ 3 s; старт GUI до интерактивной ленты p75 ≤ 2 s на mid-range телефоне.

Проверка:

- замер на стенде двух машин + телефон;
- evidence: таблица замеров в карточке приёмки.

Зависимости: DUD-NET-101  
ADR: не требуется

### DUD-PRD-140

Priority: P2  
Status: Accepted · 2026-07-28

Модель на MVP: **Community без runtime-лицензии и без callhome**. Дистрибутив
семьи ставится локально (P085); Дьяк/лицензии не требуются для квартирного
LAN-чата.

Исходный код публикуется как **source-available** по PolyForm Noncommercial
License 1.0.0: разрешены аудит, личное изучение и иное некоммерческое
использование; коммерческое использование требует отдельного разрешения
правообладателя. Это не OSI Open Source. Канонический репозиторий — Forgejo,
публичное зеркало — GitHub.

Правообладатель сохраняет возможность позже перелицензировать код, выпустить
его под OSI-одобренной лицензией или передать права. Внешние изменения кода не
принимаются без отдельного соглашения о правах.

Проверка:

- в коде нет callhome-эндпоинтов (`./scripts/no_callhome_test.sh`, P096);
- статус Accepted с датой; runtime update-check запрещён.

  notice;

  Forgejo и публичное GitHub-зеркало.

Зависимости: нет  
ADR: не требуется для Community/no-callhome
