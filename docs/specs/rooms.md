# DUD-ROOM — Комнаты без кодов

Статус документа: Accepted · 2026-07-28  
Владелец: ДУДКА

## Назначение

На одной LAN семья может переключаться между **именованными каналами** без invite-кодов и облака. Канал — метка на сообщениях; discovery общий.

### Non-goals

- Приватные комнаты с паролем/E2E.
- Синхронизация истории канала offline-first за пределами хвоста 200.

## Требования

### DUD-ROOM-101

Priority: P2  
Status: Accepted

Каждый peer знает список каналов на LAN (минимум локально созданные + увиденные в ленте). Канал по умолчанию: `общий`.

Проверка:

- `GET /channels` возвращает ≥ `общий`;
- evidence: unit/API test.

### DUD-ROOM-110

Priority: P2  
Status: Accepted

`POST /channels` с `{name}` добавляет канал (без кода). Имя 1–40 символов, без `/`.

Проверка:

- повторное создание того же имени — идемпотентно;
- evidence: API test.

### DUD-ROOM-120

Priority: P2  
Status: Accepted

`POST /send` принимает опциональный `channel` (default `общий`). `GET /messages?channel=` фильтрует ленту. TUI/GUI показывают список каналов.

Проверка:

- сообщение в канале A не видно в фильтре B;
- evidence: protocol/unit + TUI frame содержит «КАНАЛЫ».
