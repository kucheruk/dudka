# Как поставить Дудку семье за 5 минут

Без аккаунтов Дудки, без облака, без «зарегистрируйся». Нужен только общий Wi‑Fi квартиры.

## Что получите

На каждом устройстве — клиент. В одном Wi‑Fi люди видят друг друга и шлют текст/файлы.
Ник выбирается локально при первом запуске.

## Быстрый путь (macOS — самый простой сегодня)

1. Соберите или возьмите готовый архив:

```bash
./scripts/build_macos_app.sh
# → dist/dudka-macos-universal.dmg + dist/dudka-macos-universal.zip
```

2. Передайте DMG по AirDrop / флешке на Mac семьи.
3. Откройте DMG, перенесите `dudka.app` в Applications и запустите (если
   Gatekeeper ругается: ПКМ → Открыть).
4. Введите ник → сразу чат. Второй Mac в том же Wi‑Fi — то же самое.
5. Напишите строку → **ОТПРАВИТЬ**. Готово.

Цель: от DMG до первого сообщения ≤ 5 минут.

Начиная с версии 0.3.0 последующие desktop-версии скачиваются заранее. Когда
пакет проверен, в хедере загорается `АПДЕЙТ X.Y.Z`; нажмите её — Дудка
закроется и через 10 секунд запустит новую версию. Для перехода с 0.2.0 на
0.3.0 нужна последняя ручная установка, потому что в 0.2.0 апдейтера ещё нет.

## Linux

```bash
curl -fsSL https://zamoo.team/dudka/install.sh | sh
```

Скрипт ставит терминальные `dudka` и `dudkad` в `~/.local/bin`, не требует
root и не меняет системные пакеты. Запустите:

```bash
dudka
```

## Windows

Скачайте `dudka-windows-amd64.zip`, распакуйте его в любую удобную папку и
запустите `dudka.exe`. Установка и права администратора не нужны. Внутренний
движок находится в служебной подпапке; запускать его вручную не нужно.

## Поведение desktop-приложения

- Крестик скрывает Дудку в системный трей, чтобы она продолжала принимать
  сообщения в квартирной сети.
- Полный выход: меню иконки в трее → **Выйти**.
- Настройки → **Запускать при входе в систему** включает пользовательский
  автозапуск без прав администратора; приложение запускается скрытым.
- Новые чужие сообщения показываются красным числом на иконке. При открытии
  окна число обнуляется.

## Android

```bash
./scripts/build_android_apk.sh
adb install -r dist/dudka-android.apk
```

Или передайте APK по USB/файлообмену и откройте на телефоне (разрешить установку из неизвестных источников).
Пока GUI на телефоне удобнее стыковать с `dudkad` на десктопе в той же LAN (см. `dist/BUILD-ANDROID.md`).

## iOS

Unsigned build: `./scripts/build_ios_app.sh`.  
Установка на iPhone семьи — ad-hoc или TestFlight: [`build-ios.md`](build-ios.md) (нужен Apple ID / Team владельца, не аккаунт Дудки).

## Правила квартиры

- Все устройства в **одном Wi‑Fi** (гость-сеть часто режет client isolation — тогда «НИКОГО РЯДОМ»).
- Интернет не нужен для чата; GUI обращается к `zamoo.team` только за
  публичным manifest обновления и ничего о чате или устройстве не отправляет.
- Ник можно сменить в настройках / TUI — старые сообщения не переписываются.

## Если не видит соседей

1. Тот же SSID? Не VPN «весь трафик»?
2. На роутере выключить AP/client isolation.
3. Desktop: кнопка **ИСКАТЬ** / `POST /scan` (TUI/API).
4. Смоук по платформам: [`platform-smoke.md`](platform-smoke.md).
